# AI SIGNAL

AI 기술·산업의 X 게시물, 공식 발표, 기술 문서, 논문, 저장소를 검증하고 연결하는 공개 지식 아카이브.

공개 분석·검증·발행의 정본은 [EDITORIAL_STANDARD.md](EDITORIAL_STANDARD.md)이다. 공개 글과 개인 프로젝트 내부 연구를 분리한다.

## 운영 원칙
- 사용자가 X·기술 블로그·공식 문서·논문·저장소 링크 또는 본문을 공유한다. 2026-10-21부터 2주간 X API 미사용.
- 원문 접근 불가 시 명시하고 본문을 요청한다. 미확인 내용은 추정하여 채우지 않는다.
- 한국어 상세 번역을 우선 제공한다. 원문 인용은 저작권상 짧은 핵심 구절만 보존하고 나머지는 충실하게 요약 번역한다.
- 게시자·KST 일시·원문 링크·확인 상태, 배경, 용어, 기술·실무·커리어 영향, 중요도, 검증 상태를 기록한다.
- 사실 / 게시자 주장 / AI 해석·전망 / 미검증을 구분한다.
- 중요하지 않은 글은 낮은 중요도로 평가한다.
- 새 게시물마다 INDEX와 관련 topics 및 과거 주장을 확인하고 연결한다. 근거 없는 연결은 만들지 않는다.
- 모델 활용 방식은 API 종량제 / 구독형 코딩 도구 / 공개 가중치 로컬 실행으로 구분한다.
- 자동 수집·코드 개발은 별도 요청 없이는 진행하지 않는다.
- 2026-11-04에 공유량·불편·누락·유용성·자동 수집 필요성을 평가한다.

## 문서 구조
- INDEX.md: 게시물 등록부와 연결
- posts/SIGNAL-NNN.md: 게시물별 상세 기록
- topics/*.md: 주제별 누적 지식과 반증
- reviews/*.md: 주기적 회고

## 갱신 규칙
새 글 등록 시 중복 URL 확인 → 원문 검증 → 상세 분석 → 주장별 증거 수준 기록 → 편집 검수 → 연결 문서 갱신 → 공개 사이트 표시 확인 → 변경 사항 보고.
출처 확인이 불완전하면 provisional 상태로 남긴다. 모델의 과거 응답만으로 사실을 확정하지 않는다.
